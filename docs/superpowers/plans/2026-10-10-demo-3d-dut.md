# Démo 3D isométrique du DUT — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Une page autonome `demo-3d.html` qui joue une animation 3D isométrique de 75 s montrant le parcours d'un DUT (création → validation OIC → QR → route → contrôle → livraison → journal d'audit), exportable en MP4 1920×1080.

**Architecture:** Le scénario est une donnée (`scenario.js`). Une fonction pure `stateAt(ms)` en dérive l'état complet de la scène (caméra, véhicules, effets, étiquettes, sous-titres) ; elle est testée dans Node. Three.js r186 (vendorisé, sans build, via `importmap`) ne fait que dessiner cet état ; un calque HTML porte étiquettes, sous-titres et journal d'audit. La lecture avance le temps via un unique pilote `requestAnimationFrame` ; l'export Playwright appelle `seek(ms)` image par image puis ffmpeg assemble.

**Tech Stack:** Three.js r186 (WebGLRenderer, OrthographicCamera, RoundedBoxGeometry), JavaScript ES modules sans build, Node 22 (`node:assert`), Playwright (déjà dans `tools/video-export`), ffmpeg.

**Spec:** `docs/superpowers/specs/2026-10-10-demo-3d-dut-design.md`

## Global Constraints

- Three.js **r186** exactement, vendorisé dans `js/demo3d/vendor/`, aucun CDN à l'exécution.
- Aucune étape de build, aucune dépendance runtime ajoutée à la plateforme.
- `js/demo3d/` exclu du pré-cache PWA (`tools/pwa/precache.mjs`).
- Durée totale **75 000 ms**, 8 plans contigus, 1920×1080, 25 i/s.
- Horloge unique : dans `js/demo3d` hors `player.js` et `vendor/`, interdits `requestAnimationFrame`, `setTimeout`, `setInterval`, `Date.now`, `performance.now`, `Math.random`. Partout dans `js/demo3d` : pas de `innerHTML`. Dans `js/demo3d/demo3d.css` : pas de `transition`, `animation`, `@keyframes`.
- Textes injectés via `textContent` uniquement.
- Couleurs : uniquement via `js/demo3d/palette.js` (logo OIC ~70 %, touches ivoiriennes ~30 %). L'orange est réservé au camion suivi.
- Police : Instrument Sans (Google Fonts, comme `index.html`).
- Communication et textes de la démo en français. Commits sans mention d'auteur IA.
- Tests : scripts Node à assertions, lancés par `node tests/demo3d.test.mjs` (convention du dépôt).

## Review Focus

1. **`seek` hors bornes ou non numérique** (négatif, > 75 000, `NaN`) → l'état est celui de la borne la plus proche, jamais d'exception. Test dans Task 3.
2. **Fenêtre non 16:9 / redimensionnée** → la scène reste en 16:9 (letterbox) et les étiquettes restent collées à leur objet. Test de `frustum` et `ndcToPixels` dans Task 3 et Task 7.
3. **Onglet masqué puis réaffiché pendant la lecture** → pas de saut brutal de plusieurs secondes : l'avance par image est plafonnée à 100 ms. Test de `advance` dans Task 4.
4. **WebGL indisponible** → message clair renvoyant au MP4, pas de page blanche. Vérification manuelle dans Task 4 (lancement Chromium avec `--disable-gpu --disable-software-rasterizer`).
5. **Police pas encore chargée au moment de la capture** → les textures de texte (livrées, enseignes) et le calque ne sont dessinés qu'après `document.fonts.load`. `ready` n'est exposé qu'après. Vérifié par les images fixes de Task 4.

```js
/** Validation structurelle du scénario. Retourne la liste des erreurs (vide = valide). */
const NAMED_STOPS = new Set(['start', 'checkpoint', 'end']);

export function validateScenario({ TOTAL_MS, SHOTS, KEYS, SPANS, AUDIT, DUT_STATUSES, ROUTES }) {
  const errors = [];
  let cursor = 0;
  for (const shot of SHOTS) {
    if (shot.at !== cursor) errors.push(`plan ${shot.id} non contigu (attendu ${cursor}, trouvé ${shot.at})`);
    if (!(shot.duration > 0)) errors.push(`plan ${shot.id} : durée invalide`);
    if (typeof shot.subtitle !== 'string' || !shot.subtitle.trim()) errors.push(`plan ${shot.id} : sous-titre vide`);
    cursor = shot.at + shot.duration;
  }
  if (cursor !== TOTAL_MS) errors.push(`durée totale ${cursor} ≠ ${TOTAL_MS}`);

  for (const [name, series] of Object.entries(KEYS)) {
    if (series[0][0] !== 0) errors.push(`KEYS.${name} ne commence pas à 0`);
    if (series[series.length - 1][0] !== TOTAL_MS) errors.push(`KEYS.${name} ne finit pas à ${TOTAL_MS}`);
    for (let i = 1; i < series.length; i += 1) {
      if (series[i][0] < series[i - 1][0]) errors.push(`KEYS.${name} non trié à l'indice ${i}`);
    }
  }
  for (const [, status] of KEYS.dutStatus) if (!DUT_STATUSES.includes(status)) errors.push(`état DUT inconnu : ${status}`);
  for (const [, stop] of KEYS.truckRoute) if (!NAMED_STOPS.has(stop)) errors.push(`arrêt camion inconnu : ${stop}`);

/** Interpolation pure, sans état ni horloge. */
export const ease = Object.freeze({
  linear: (t) => t,
  inOut: (t) => (t < 0.5 ? 4 * t * t * t : 1 - ((-2 * t + 2) ** 3) / 2),
  out: (t) => 1 - (1 - t) ** 3,
});

export const clamp = (v, a, b) => Math.min(b, Math.max(a, v));
export const lerp = (a, b, k) => a + (b - a) * k;

/** Valeur interpolée d'une série [[ms, valeur], ...] ; valeur = nombre ou tableau de nombres. */
export function keyed(keys, ms, easeFn = ease.inOut) {
  if (ms <= keys[0][0]) return keys[0][1];
  for (let i = 1; i < keys.length; i += 1) {
    const [t1, v1] = keys[i];
    if (ms <= t1) {
      const [t0, v0] = keys[i - 1];
      const k = t1 === t0 ? 1 : easeFn((ms - t0) / (t1 - t0));
      return Array.isArray(v0) ? v0.map((x, j) => lerp(x, v1[j], k)) : lerp(v0, v1, k);
    }
  }
  return keys[keys.length - 1][1];
}

/** Valeur en escalier : la dernière clé atteinte. */
export function stepped(keys, ms) {
  let value = keys[0][1];
  for (const [t, v] of keys) {
    if (ms >= t) value = v;
    else break;
  }
  return value;
}

export const within = ([a, b], ms) => ms >= a && ms < b;
export const spanProgress = ([a, b], ms) => clamp((ms - a) / (b - a), 0, 1);
/** Monte vite, tient, redescend vite : 0 → 1 → 1 → 0. */
export const plateau = (p) => clamp(Math.min(p * 4, (1 - p) * 4), 0, 1);

import { clamp } from './keyframes.js';

/** Lissage de Chaikin : arrondit les coins, conserve les extrémités. */
export function smooth(points, iterations = 3) {
  let pts = points.map((p) => [p[0], p[1]]);
  for (let n = 0; n < iterations; n += 1) {
    const out = [pts[0]];
    for (let i = 0; i < pts.length - 1; i += 1) {
      const [ax, az] = pts[i];
      const [bx, bz] = pts[i + 1];
      out.push([ax * 0.75 + bx * 0.25, az * 0.75 + bz * 0.25], [ax * 0.25 + bx * 0.75, az * 0.25 + bz * 0.75]);
    }
    out.push(pts[pts.length - 1]);
    pts = out;
  }
  return pts;
}

/** Polyligne paramétrée par la longueur. */
export function makePath(points) {
  const segs = [];
  let length = 0;
  for (let i = 0; i < points.length - 1; i += 1) {
    const a = points[i];
    const b = points[i + 1];
    const len = Math.hypot(b[0] - a[0], b[1] - a[1]);
    segs.push({ a, b, len, start: length });
    length += len;
  }
  return { points, segs, length };
}

/** Position et cap à l'avancement u ∈ [0, 1]. Cap = atan2(dx, dz) (avant du véhicule vers +z). */
export function sampleAt(path, u) {
  const d = clamp(u, 0, 1) * path.length;
  let seg = path.segs[path.segs.length - 1];
  for (const s of path.segs) {
    if (d <= s.start + s.len && s.len > 0) { seg = s; break; }
  }
  const k = seg.len ? clamp((d - seg.start) / seg.len, 0, 1) : 0;
  return {
    x: seg.a[0] + (seg.b[0] - seg.a[0]) * k,
    z: seg.a[1] + (seg.b[1] - seg.a[1]) * k,
    heading: Math.atan2(seg.b[0] - seg.a[0], seg.b[1] - seg.a[1]),
  };
}

/** Avancement u du point de la trajectoire le plus proche de [x, z]. */
export function nearestU(path, [px, pz]) {
  let best = { u: 0, dist: Infinity };
  for (const s of path.segs) {
    const dx = s.b[0] - s.a[0];
    const dz = s.b[1] - s.a[1];
    const k = s.len ? clamp(((px - s.a[0]) * dx + (pz - s.a[1]) * dz) / (s.len * s.len), 0, 1) : 0;
    const dist = Math.hypot(px - (s.a[0] + dx * k), pz - (s.a[1] + dz * k));
    if (dist < best.dist) best = { u: (s.start + s.len * k) / path.length, dist };
  }
  return best;
}

/**
 * Pilote de lecture — SEUL fichier de js/demo3d autorisé à utiliser
 * requestAnimationFrame. Il ne calcule aucun état : il fait avancer un temps
 * et appelle renderAt(ms).
 */
export const MAX_STEP_MS = 100;

/** Avance le temps d'une image, plafonnée (onglet masqué, machine lente). */
export function advance(position, deltaMs, duration) {
  const step = Math.min(Math.max(deltaMs, 0), MAX_STEP_MS);
  return Math.min(duration, position + step);
}

export function startPlayer({ renderAt, duration, button }) {
  let playing = false;
  let position = 0;
  let last = null;
  const label = () => {
    button.textContent = playing ? 'Pause' : position >= duration ? 'Revoir' : 'Lire';
    button.setAttribute('aria-pressed', String(playing));
  };
  const tick = (ts) => {
    if (playing) {
      if (last !== null) position = advance(position, ts - last, duration);
      last = ts;
      renderAt(position);
      if (position >= duration) { playing = false; label(); }
    }
    requestAnimationFrame(tick);
  };
  const toggle = () => {
    if (!playing && position >= duration) position = 0;
    playing = !playing;
    last = null;
    label();
  };
  button.addEventListener('click', toggle);
  document.addEventListener('keydown', (e) => {
    if (e.code === 'Space' && e.target === document.body) { e.preventDefault(); toggle(); }
  });
  label();
  requestAnimationFrame(tick);
}

/** Briques de construction des maquettes « jouet » : formes arrondies, aucun contour. */
import * as THREE from 'three';
import { RoundedBoxGeometry } from 'three/addons/geometries/RoundedBoxGeometry.js';

const materials = new Map();

export function mat(hex, opts = {}) {
  const key = `${hex}|${JSON.stringify(opts)}`;
  if (!materials.has(key)) {
    materials.set(key, new THREE.MeshStandardMaterial({ color: hex, roughness: 0.72, metalness: 0, ...opts }));
  }
  return materials.get(key);
}

/** Couleur assombrie (k < 1) ou éclaircie (k > 1). */
export function shade(hex, k) {
  return `#${new THREE.Color(hex).multiplyScalar(k).getHexString()}`;
}

function shadowed(mesh) {
  mesh.castShadow = true;
  mesh.receiveShadow = true;
  return mesh;
}

/** Pavé à angles arrondis, centré sur son origine. */
export function rbox(w, h, d, r, hex, opts) {
  const radius = Math.min(r, w / 2, h / 2, d / 2);
  return shadowed(new THREE.Mesh(new RoundedBoxGeometry(w, h, d, 3, radius), mat(hex, opts)));
}

export function cyl(rTop, rBottom, h, hex, seg = 20) {
  return shadowed(new THREE.Mesh(new THREE.CylinderGeometry(rTop, rBottom, h, seg), mat(hex)));
}

/** Surface plane au sol (marquage, dalle, route). */
export function flat(w, d, hex, y = 0.01) {
  const m = new THREE.Mesh(new THREE.PlaneGeometry(w, d), mat(hex, { roughness: 1 }));
  m.rotation.x = -Math.PI / 2;
  m.position.y = y;
  m.receiveShadow = true;
  return m;
}

export function at(obj, x, y, z) {
  obj.position.set(x, y, z);
  return obj;
}

export function canvasTexture(w, h, draw) {
  const canvas = document.createElement('canvas');
  canvas.width = w;
  canvas.height = h;
  draw(canvas.getContext('2d'), w, h);
  const tex = new THREE.CanvasTexture(canvas);
  tex.colorSpace = THREE.SRGBColorSpace;
  tex.anisotropy = 8;
  return tex;
}

/** Plan texturé (enseigne, livrée), face vers +z. */
export function decal(w, h, texture) {
  return new THREE.Mesh(
    new THREE.PlaneGeometry(w, h),
    new THREE.MeshStandardMaterial({ map: texture, transparent: true, roughness: 0.8 }),
  );
}

let shadowTexture = null;
/** Ombre de contact floue posée au sol sous un objet. */
export function contactShadow(w, d, opacity = 0.32) {
  shadowTexture ??= canvasTexture(128, 128, (g, W, H) => {
    const grad = g.createRadialGradient(W / 2, H / 2, 0, W / 2, H / 2, W / 2);
    grad.addColorStop(0, 'rgba(18, 32, 58, 1)');
    grad.addColorStop(1, 'rgba(18, 32, 58, 0)');
    g.fillStyle = grad;
    g.fillRect(0, 0, W, H);
  });
  const m = new THREE.Mesh(
    new THREE.PlaneGeometry(w, d),
    new THREE.MeshBasicMaterial({ map: shadowTexture, transparent: true, opacity, depthWrite: false }),
  );
  m.rotation.x = -Math.PI / 2;
  m.position.y = 0.04;
  m.renderOrder = 1;
  return m;
}

/** Camion porte-conteneur 20 pieds, avant vers +z, origine au sol au centre. */
import * as THREE from 'three';
import { PALETTE } from '../palette.js';
import { rbox, cyl, at, canvasTexture, decal, contactShadow, mat } from './kit.js';

export const TRUCK_SIZE = Object.freeze({ w: 2.6, h: 4.0, d: 10.2 });

function drawWave(g, x, y, w, h) {
  [PALETTE.orange, '#FFFFFF', PALETTE.vert].forEach((color, i) => {
    g.strokeStyle = color;
    g.lineWidth = h * 0.16;
    g.lineCap = 'round';
    g.beginPath();
    g.moveTo(x, y + h * (0.55 + i * 0.18));
    g.bezierCurveTo(x + w * 0.35, y + h * (0.15 + i * 0.18), x + w * 0.65, y + h * (0.75 + i * 0.18), x + w, y + h * (0.35 + i * 0.18));
    g.stroke();
  });
}

function sideTexture({ stripe, brand, wave }) {
  return canvasTexture(1024, 384, (g, w, h) => {
    g.fillStyle = '#FFFFFF';
    g.fillRect(0, 0, w, h);
    g.fillStyle = stripe;
    g.fillRect(0, h * 0.8, w, h * 0.2);
    if (wave) drawWave(g, w * 0.05, h * 0.16, w * 0.24, h * 0.42);
    g.fillStyle = PALETTE.marine;
    g.font = '700 74px "Instrument Sans", sans-serif';
    g.textBaseline = 'middle';
    g.fillText(brand, w * (wave ? 0.34 : 0.08), h * 0.42);
  });
}

export function createTruck({ cab, stripe, brand, wave = false }) {
  const g = new THREE.Group();
  g.add(contactShadow(3.6, 11.4));

  // Châssis
  g.add(at(rbox(2.3, 0.4, 9.8, 0.1, PALETTE.quai), 0, 1.05, 0));

  // Conteneur 20 pieds + livrée sur les deux flancs
  g.add(at(rbox(2.45, 2.6, 6.1, 0.1, '#FFFFFF'), 0, 2.55, -1.85));
  const tex = sideTexture({ stripe, brand, wave });
  for (const side of [-1, 1]) {
    const d = decal(6.0, 2.25, tex);
    d.rotation.y = side * Math.PI / 2;
    at(d, side * 1.235, 2.55, -1.85);
    g.add(d);
  }
  // Portes arrière
  g.add(at(rbox(2.3, 2.4, 0.08, 0.04, '#E6EAF0'), 0, 2.55, -4.92));

  // Cabine (avant vers +z)
  g.add(at(rbox(2.5, 2.3, 2.6, 0.38, cab), 0, 2.4, 3.3));
  g.add(at(rbox(2.0, 0.9, 0.08, 0.04, PALETTE.vitre), 0, 2.95, 4.62));
  for (const side of [-1, 1]) {
    g.add(at(rbox(0.06, 0.75, 1.0, 0.03, PALETTE.vitre), side * 1.26, 2.9, 3.55));
    g.add(at(rbox(0.12, 0.5, 0.3, 0.05, PALETTE.quai), side * 1.4, 2.75, 4.3));
    const light = rbox(0.42, 0.22, 0.06, 0.04, '#FFF6D8', { emissive: '#FFF0C0', emissiveIntensity: 0.6 });
    g.add(at(light, side * 0.85, 1.55, 4.63));
  }
  g.add(at(rbox(1.3, 0.5, 0.06, 0.04, '#4A5260'), 0, 1.75, 4.62));
  g.add(at(rbox(2.5, 0.35, 0.3, 0.08, '#B9C1CC'), 0, 0.95, 4.55));

  // Roues : 3 essieux
  for (const z of [3.6, -2.4, -3.7]) {

    }
  }
  g.userData.size = TRUCK_SIZE;
  return g;
}

/** Renderer, caméra orthographique isométrique, lumières. */
import * as THREE from 'three';
import { PALETTE } from './palette.js';
import { frustum } from './timeline.js';

const ISO_DIR = new THREE.Vector3(1, 0.95, 1).normalize();
const CAMERA_DISTANCE = 220;
const SUN_OFFSET = new THREE.Vector3(-45, 85, 35);
const SHADOW_HALF = 75;

export function createStage(canvas, { preserveDrawingBuffer }) {
  let renderer;
  try {
    renderer = new THREE.WebGLRenderer({ canvas, antialias: true, preserveDrawingBuffer });
  } catch {
    return null;
  }
  renderer.setPixelRatio(Math.min(window.devicePixelRatio || 1, 2));
  renderer.shadowMap.enabled = true;
  renderer.shadowMap.type = THREE.PCFSoftShadowMap;
  renderer.setClearColor(PALETTE.fond);

  const scene = new THREE.Scene();
  const camera = new THREE.OrthographicCamera(-1, 1, 1, -1, 1, 800);

  scene.add(new THREE.HemisphereLight(PALETTE.cielHemi, PALETTE.solHemi, 1.7));
  const sun = new THREE.DirectionalLight(PALETTE.soleil, 2.3);
  sun.castShadow = true;
  sun.shadow.mapSize.set(4096, 4096);
  Object.assign(sun.shadow.camera, { left: -SHADOW_HALF, right: SHADOW_HALF, top: SHADOW_HALF, bottom: -SHADOW_HALF, near: 1, far: 320 });
  sun.shadow.bias = -0.0004;
  sun.shadow.normalBias = 0.03;
  scene.add(sun, sun.target);

  const target = new THREE.Vector3();
  function resize() {
    const w = canvas.clientWidth;
    const h = canvas.clientHeight;
    const size = renderer.getSize(new THREE.Vector2());
    if (size.x !== w || size.y !== h) renderer.setSize(w, h, false);
    return w / h;
  }

  function frame({ x, z, zoom }) {
    const { halfW, halfH } = frustum(resize(), zoom);
    Object.assign(camera, { left: -halfW, right: halfW, top: halfH, bottom: -halfH });
    target.set(x, 0, z);
    camera.position.copy(target).addScaledVector(ISO_DIR, CAMERA_DISTANCE);
    camera.lookAt(target);
    camera.updateProjectionMatrix();
    camera.updateMatrixWorld();
    sun.position.copy(target).add(SUN_OFFSET);
    sun.target.position.copy(target);
    sun.target.updateMatrixWorld();
  }

  return { renderer, scene, camera, frame, render: () => renderer.render(scene, camera) };
}

/**
 * Rendu de la démo 3D (demo-3d.html?render=1) — outil de développement.
 * Pilote le temps virtuel : seek(ms) puis capture de #stage (canvas + calque).
 *
 * Usage (un serveur doit servir le dépôt) :

import { mkdirSync } from 'node:fs';
import { resolve as resolvePath } from 'node:path';
import { chromium } from 'playwright';

const WIDTH = 1920;
const HEIGHT = 1080;
const REPO_ROOT = resolvePath(import.meta.dirname, '..', '..');
const OUT_DIR = resolvePath(REPO_ROOT, 'output/demo3d');

function parseArgs(argv) {
  const args = { port: 8080, stills: [], all: false, gl: null };
  for (let i = 2; i < argv.length; i += 1) {
    const a = argv[i];
    if (a === '--port') args.port = Number(argv[++i]);
    else if (a === '--still') args.stills = argv[++i].split(',').map(Number);
    else if (a === '--all') args.all = true;
    else if (a === '--gl') args.gl = argv[++i];

export async function openDemo({ port, gl }) {

import { canvasTexture } from './kit.js';

const LOGO_URL = 'assets/images/logo-oic.jpg';

function loadImage(url) {
  return new Promise((resolve, reject) => {
    const img = new Image();
    img.onload = () => resolve(img);
    img.onerror = () => reject(new Error(`Logo introuvable : ${url}`));
    img.src = url;
  });
}

export async function loadLogoTexture() {
  const img = await loadImage(LOGO_URL);
  return canvasTexture(512, 512, (g, w, h) => {
    g.fillStyle = '#FFFFFF';
    g.beginPath();
    g.arc(w / 2, h / 2, w / 2 - 4, 0, Math.PI * 2);
    g.fill();
    // Le logo source est carré avec marges : on recadre sur le sigle et le nom.
    const crop = { sx: img.width * 0.04, sy: img.height * 0.18, sw: img.width * 0.92, sh: img.height * 0.56 };
    const dw = w * 0.78;
    const dh = dw * (crop.sh / crop.sw);
    g.drawImage(img, crop.sx, crop.sy, crop.sw, crop.sh, (w - dw) / 2, (h - dh) / 2, dw, dh);
  });
}

/** Entrepôt à toit nervuré en bâtière, quais numérotés sur la face +z. */
import * as THREE from 'three';
import { PALETTE } from '../palette.js';
import { rbox, flat, at, mat, shade, canvasTexture, decal } from './kit.js';

const PITCH = 0.2;

function plateTexture(text, bg = PALETTE.marine) {
  return canvasTexture(256, 128, (g, w, h) => {
    g.fillStyle = bg;
    g.fillRect(0, 0, w, h);
    g.fillStyle = '#FFFFFF';
    g.font = '700 64px "Instrument Sans", sans-serif';
    g.textAlign = 'center';
    g.textBaseline = 'middle';
    g.fillText(text, w / 2, h / 2 + 4);
  });
}

function signTexture(text) {
  return canvasTexture(1024, 160, (g, w, h) => {
    g.fillStyle = '#FFFFFF';
    g.fillRect(0, 0, w, h);
    g.fillStyle = PALETTE.marine;
    g.font = '700 84px "Instrument Sans", sans-serif';
    g.textAlign = 'center';
    g.textBaseline = 'middle';
    g.fillText(text, w / 2, h / 2 + 6);
  });
}

function dock(x, z, number) {
  const g = new THREE.Group();
  g.add(at(rbox(2.8, 3.2, 0.25, 0.1, PALETTE.marine), x, 1.6, z + 0.05));
  g.add(at(rbox(2.2, 2.7, 0.2, 0.05, PALETTE.quai), x, 1.4, z + 0.12));
  g.add(at(rbox(1.6, 1.2, 0.7, 0.08, PALETTE.carton), x, 0.62, z - 0.05));
  g.add(at(rbox(1.7, 0.16, 0.8, 0.03, PALETTE.bois), x, 0.08, z - 0.05));
  const plate = decal(0.7, 0.35, plateTexture(String(number).padStart(2, '0')));
  g.add(at(plate, x, 3.45, z + 0.2));
  for (const side of [-1, 1]) {
    g.add(at(rbox(0.25, 0.5, 0.3, 0.06, PALETTE.pneu), x + side * 1.2, 0.35, z + 0.25));
    g.add(at(flat(0.15, 9, PALETTE.marquageJaune, 0.035), x + side * 1.7, 0.035, z + 4.6));
  }
  return g;
}

export function createWarehouse({ w, d, h, wall, roof, doors, facade, logo = null }) {
  const g = new THREE.Group();
  g.add(at(rbox(w, h, d, 0.25, wall), 0, h / 2, 0));

  // Pignons triangulaires
  const slabD = d / 2 + 0.7;
  const rise = Math.sin(PITCH) * slabD;
  const tri = new THREE.Shape([new THREE.Vector2(-d / 2, 0), new THREE.Vector2(d / 2, 0), new THREE.Vector2(0, rise)]);
  const prism = new THREE.Mesh(new THREE.ExtrudeGeometry(tri, { depth: w, bevelEnabled: false }), mat(wall));
  prism.rotation.y = Math.PI / 2;
  prism.position.set(-w / 2, h, 0);
  prism.castShadow = true;
  g.add(prism);

  // Pans de toit nervurés
  const ribColor = shade(roof, 0.86);
  for (const side of [-1, 1]) {
    const slab = rbox(w + 0.8, 0.45, slabD, 0.15, roof);
    slab.position.set(0, h + 0.2 + rise / 2, side * (slabD / 2) * Math.cos(PITCH));
    slab.rotation.x = side * PITCH;
    for (let x = -w / 2 + 0.7; x < w / 2; x += 1.2) slab.add(at(rbox(0.14, 0.1, slabD - 0.3, 0.04, ribColor), x, 0.27, 0));
    if (logo && side === 1) {
      const disc = new THREE.Mesh(new THREE.CircleGeometry(Math.min(2.6, slabD * 0.38), 48), new THREE.MeshStandardMaterial({ map: logo, roughness: 0.8 }));
      disc.rotation.x = -Math.PI / 2;
      slab.add(at(disc, -w / 4, 0.24, 0));
    }
    g.add(slab);
  }

  // Quais sur la face +z
  for (let i = 0; i < doors; i += 1) {
    const x = -w / 2 + (i + 0.5) * (w / doors);
    g.add(dock(x, d / 2, i + 1));
  }

  // Enseigne de façade
  if (facade) g.add(at(decal(Math.min(w * 0.6, 12), 1.0, signTexture(facade)), 0, h - 0.7, d / 2 + 0.16));
  g.userData.dockFront = d / 2;
  return g;
}

export function createStack({ cols, rows, levels, seed = 0 }) {
  const g = new THREE.Group();
  const colors = PALETTE.conteneurs;
  for (let c = 0; c < cols; c += 1) {

/** Trajet au sol : ruban plein derrière l'avancement u, points devant. */
import * as THREE from 'three';
import { sampleAt } from '../path.js';

const Y = 0.07;

export function createTrail(path, { solid, dashed, width = 0.9, step = 0.5, dashEvery = 1.6 }) {
  const object = new THREE.Group();
  const n = Math.max(2, Math.ceil(path.length / step) + 1);
  const pts = Array.from({ length: n }, (_, i) => sampleAt(path, i / (n - 1)));
  const pos = new Float32Array((n - 1) * 6 * 3);
  let o = 0;
  const edge = (p, side) => [p.x + Math.cos(p.heading) * side * (width / 2), Y, p.z - Math.sin(p.heading) * side * (width / 2)];
  for (let i = 0; i < n - 1; i += 1) {
    const a = pts[i];
    const b = pts[i + 1];
    const quad = [edge(a, 1), edge(a, -1), edge(b, 1), edge(a, -1), edge(b, -1), edge(b, 1)];
    for (const v of quad) { pos.set(v, o); o += 3; }
  }
  const geo = new THREE.BufferGeometry();
  geo.setAttribute('position', new THREE.BufferAttribute(pos, 3));
  const ribbon = new THREE.Mesh(geo, new THREE.MeshBasicMaterial({ color: solid, side: THREE.DoubleSide }));
  ribbon.renderOrder = 2;
  object.add(ribbon);

  const dots = [];
  const dotGeo = new THREE.CircleGeometry(0.28, 16);
  const dotMat = new THREE.MeshBasicMaterial({ color: dashed });
  const count = Math.floor(path.length / dashEvery);
  for (let i = 1; i <= count; i += 1) {
    const u = (i * dashEvery) / path.length;
    const p = sampleAt(path, u);
    const dot = new THREE.Mesh(dotGeo, dotMat);
    dot.rotation.x = -Math.PI / 2;
    dot.position.set(p.x, Y, p.z);
    dot.renderOrder = 2;
    object.add(dot);
    dots.push({ dot, u });
  }

  return {
    object,
    update(u) {
      object.visible = u !== null;
      if (u === null) return;
      geo.setDrawRange(0, Math.floor(u * (n - 1)) * 6);
      for (const { dot, u: du } of dots) dot.visible = du > u + 0.004;
    },
  };
}

const T = 0.12;

export function createBrackets({ w, h, d }) {
  const object = new THREE.Group();
  const inner = new THREE.Group();
  object.add(inner);

  const W = w + PAD * 2;

  const L = Math.min(W, H, D) * 0.28;
  for (const sx of [-1, 1]) for (const sy of [0, 1]) for (const sz of [-1, 1]) {
    const cx = (sx * W) / 2;
    const cy = sy * H;
    const cz = (sz * D) / 2;
    const arms = [
      [L, T, T, cx - (sx * L) / 2, cy, cz],
      [T, L, T, cx, cy + (sy ? -L / 2 : L / 2), cz],
      [T, T, L, cx, cy, cz - (sz * L) / 2],
    ];
    for (const [aw, ah, ad, x, y, z] of arms) {
      const m = new THREE.Mesh(new THREE.BoxGeometry(aw, ah, ad), mat);
      m.position.set(x, y, z);
      inner.add(m);

    object,

/** Scan du QR : faisceau qui monte du scanner « vers le système », anneau qui le parcourt. */
import * as THREE from 'three';
import { PALETTE } from '../palette.js';

const HEIGHT = 30;

export function createScan([x, y, z]) {
  const object = new THREE.Group();
  object.position.set(x, y, z);
  const beamMat = new THREE.MeshBasicMaterial({ color: PALETTE.ciel, transparent: true, depthWrite: false });
  const beam = new THREE.Mesh(new THREE.CylinderGeometry(0.09, 0.09, 1, 12), beamMat);
  const ringMat = new THREE.MeshBasicMaterial({ color: PALETTE.royal, transparent: true, depthWrite: false });
  const ring = new THREE.Mesh(new THREE.TorusGeometry(0.6, 0.08, 8, 32), ringMat);
  ring.rotation.x = Math.PI / 2;
  object.add(beam, ring);
  return {
    object,
    update(p) {
      object.visible = p !== null;
      if (p === null) return;
      const grow = Math.min(1, p * 2.5);
      beam.scale.y = HEIGHT * grow;
      beam.position.y = (HEIGHT * grow) / 2;
      beamMat.opacity = 0.75 * (1 - Math.max(0, p - 0.8) / 0.2);
      ring.position.y = HEIGHT * ((p * 3) % 1);
      ringMat.opacity = 0.9 * (1 - p * 0.3);
    },
  };
}
```

```js
/** Calque HTML : étiquette DUT qui suit son objet, sous-titres, journal d'audit. Texte via textContent. */
import * as THREE from 'three';
import { DUT_STATUS_STYLE } from '../palette.js';
import { AUDIT } from '../scenario.js';
import { ndcToPixels } from './project.js';

const SVG_NS = 'http://www.w3.org/2000/svg';
const LABEL_HEIGHT = { truck: 5.0, document: 3.2 };

/** Pictogramme QR statique (motif fixe, purement décoratif). */
function qrIcon() {
  const svg = document.createElementNS(SVG_NS, 'svg');
  svg.setAttribute('viewBox', '0 0 7 7');
  svg.setAttribute('class', 'd3-label__qr');
  svg.setAttribute('aria-hidden', 'true');
  const cells = ['0,0,3', '4,0,3', '0,4,3', '4,4,1', '6,6,1', '5,5,1', '4,6,1', '6,4,1'];
  for (const c of cells) {
    const [x, y, s] = c.split(',').map(Number);
    const r = document.createElementNS(SVG_NS, 'rect');
    for (const [k, v] of [['x', x], ['y', y], ['width', s], ['height', s], ['fill', '#FFFFFF']]) r.setAttribute(k, String(v));
    svg.append(r);
  }
  return svg;
}

function createLabel(container) {
  const el = document.createElement('div');
  el.className = 'd3-label';
  const id = document.createElement('span');
  id.className = 'd3-label__id';
  const num = document.createElement('span');
  num.className = 'd3-label__num';
  const qr = qrIcon();
  el.append(id, num, qr);
  container.append(el);
  return { el, id, num, qr };
}

export function createOverlay(stageEl) {
  const subtitle = stageEl.querySelector('#d3-subtitle');
  const auditEl = stageEl.querySelector('#d3-audit');
  const list = auditEl.querySelector('ol');
  const label = createLabel(stageEl.querySelector('#d3-labels'));
  const rows = AUDIT.map((row) => {
    const li = document.createElement('li');
    const time = document.createElement('time');
    time.textContent = row.time;
    const text = document.createElement('span');
    text.textContent = row.text;
    li.append(time, text);
    list.append(li);
    return li;
  });
  const v = new THREE.Vector3();

  return {
    update(s, world, stage) {
      if (subtitle.textContent !== s.subtitle.text) subtitle.textContent = s.subtitle.text;
      subtitle.style.opacity = String(s.subtitle.opacity);

      const style = DUT_STATUS_STYLE[s.dut.status];
      label.el.hidden = !style;
      if (style) {
        const idText = `DUT · ${style.label}`;
        if (label.id.textContent !== idText) label.id.textContent = idText;
        const numText = s.dut.number ?? '';
        if (label.num.textContent !== numText) label.num.textContent = numText;
        label.num.hidden = !s.dut.number;
        label.qr.style.display = s.dut.qr ? 'block' : 'none';
        label.el.style.setProperty('--tone', style.color);
        const anchor = s.dut.anchor === 'document' ? s.doc : s.truck;
        v.set(anchor.x, LABEL_HEIGHT[s.dut.anchor], anchor.z).project(stage.camera);
        const canvas = stage.renderer.domElement;
        const { left, top } = ndcToPixels(v.x, v.y, canvas.clientWidth, canvas.clientHeight);
        label.el.style.transform = `translate(${left}px, ${top}px) translate(-50%, -100%)`;
      }

      auditEl.hidden = !s.audit.visible;
      rows.forEach((li, i) => li.classList.toggle('is-lit', i < s.audit.lit));
    },
  };
}
```
